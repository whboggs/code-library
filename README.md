## How To Use This
1. Folders are organized by Platform
2. Inside each platform, you will find 2 folders: (1) The Scripts folder is home to the executable scripts (what actually runs). (2) The GTM Tags folder houses the jsdelivr scripts to add to your GTM container.

### To use Scripts that update automatically as they are improved
Use the GTM Tags folder.
jsdelivr links to the scripts found in the Scripts folder.
*Note: these may be less reliable as there can be issues with timing.*

### To use Scripts that are more reliable
Copy the script directly from the Scripts folder
