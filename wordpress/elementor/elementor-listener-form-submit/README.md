# Elementor Listerner Form Submit
Pushes a `form_submit` event to the dataLayer

## Installation
1. In GTM, create a Custom HTML Tag
2. Paste the code from elementor-listener-form-submit.html
3. Change the `form_submit` event to whatever you want – another great option is `elementor_form_submit` to keep it distinct
4. Use the event name from step 3 to create Custom Event Triggers
